# Reproducibility package / 再現パッケージ

Reproduces **Table 1, Table 2, and Table 3** of `manuscripts/methods_results.md`
(deontic markers in medical-education vs. general-medicine research articles).

`manuscripts/methods_results.md` の **Table 1・Table 2・Table 3** を再現するための
手順とスクリプトです。

---

## What is / isn't reproduced here / 再現範囲

| Stage                                                      | Reproduced here?                        |
| ---------------------------------------------------------- | --------------------------------------- |
| PubMed retrieval, full-text download                       | ❌ upstream / 対象外                    |
| PDF → text (Adobe PDF Extract API)                        | ❌ upstream / 対象外                    |
| **text (JSON) → corpus → detection → statistics** | ✅**this package / 本パッケージ** |

EN: The Adobe step is impractical to re-run, so the **already text-extracted data**
(`data/interim/cleaned_text/*.json`) is maintained as collaborator-only input
data, and everything downstream is provided as documented, runnable code that calls the existing
package in `src/normative_discourse/`.

JA: Adobe 工程は再実行が難しいため、**テキスト抽出済みデータ**は共同研究者向け入力データとして管理し、
それ以降の処理を、`src/normative_discourse/` の既存コードを呼ぶ説明付きスクリプトとして
提供します。

---

## 1. Setup / セットアップ

Requirements:

- Python ≥ 3.11
- R ≥ 4.5 with packages `arrow`, `data.table` (for Table 2 & 3 only)

```bash
# from the repository root / リポジトリルートで
pip install -r reproducibility/requirements.txt
# in R:  install.packages(c("arrow", "data.table"))
```

> **Do NOT run `pip install -e .`** — that pulls the full dependency set
> (selenium / Adobe SDK / google-genai). The wrappers put `src/` on `PYTHONPATH`
> themselves. No `.env` / API keys are needed (this path never goes online).
>
> `pip install -e .` は使わないでください（不要な依存が入ります）。ラッパが `src/` を
> `PYTHONPATH` に追加します。`.env` や API キーは不要です（ネット接続しません）。

## 3. Run / 実行

### All at once / 一括

```bash
python reproducibility/run_all.py                       # steps 00→04, 06, verify
python reproducibility/run_all.py --with-frequency      # also the optional G-test (05)
python reproducibility/run_all.py --force-detect        # if detection outputs already exist
```

### Step by step / 個別

| Step | Script                         | Produces                                                  | Reviewable core logic                                                                    |
| ---- | ------------------------------ | --------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 00   | `run_00_check_inputs.py`     | (validation)                                              | `_env.py`                                                                              |
| 01   | `run_01_build_corpus.py`     | `data/processed/articles_corpus_10yr_draft.parquet`     | `src/normative_discourse/data_io/corpus_builder.py`, `config/section_overrides.toml` |
| 02   | `run_02_strip_references.py` | `..._10yr_clean.parquet` (frozen corpus)                | `scripts/strip_discussion_references.py`                                               |
| 03   | `run_03_detect_deontic.py`   | `section_inventory.parquet`, `matches.parquet`        | `src/normative_discourse/detection/deontic_detector.py`                                |
| 04   | `run_04_meta_analysis.py`    | `results/output_meta/**` (**Table 2 & 3**)        | `scripts/meta_analysis_deontic.R`                                                      |
| 05   | `run_05_frequency_suite.py`  | `results/output/**` (secondary G-test)                  | `src/normative_discourse/stats/frequency_analysis.py`                                  |
| 06   | `run_06_table1.py`           | `reproducibility/work/table1_*.csv` (**Table 1**) | the script itself                                                                        |
| —   | `verify_numbers.py`          | pass/fail vs. manuscript                                  | the script itself                                                                        |

```bash
python reproducibility/run_01_build_corpus.py
python reproducibility/run_02_strip_references.py
python reproducibility/run_03_detect_deontic.py        # --force to overwrite existing outputs
python reproducibility/run_04_meta_analysis.py
python reproducibility/run_06_table1.py
python reproducibility/run_05_frequency_suite.py        # optional
python reproducibility/verify_numbers.py
```

> ⚠ **Step 03 caveat.** `detect-deontic` *resumes* from and *appends* to existing
> output. `run_03` therefore refuses to run when `section_inventory.parquet` /
> `matches.parquet` already exist; pass `--force` to delete and regenerate.
>
> ⚠ **Step 03 注意.** detect-deontic は既存出力を resume/append します。`run_03` は
> 既存出力があると停止します。`--force` で削除して再生成してください。

## 4. Verify / 検証

```bash
python reproducibility/verify_numbers.py
```

Reads the parquet/CSV outputs **directly** (not the console display, which can
break on Windows Unicode) and checks them against the manuscript. Exits non-zero
on any mismatch. Expected (all currently PASS, 33/33):

- **Table 1**: N = 10,743 (`~is_non_imrad`); ME 3,743 / GM 7,000; period
  5,206 / 5,537; per-journal counts; section presence (Intro/Methods/Results
  10,743, Discussion 10,731).
- **Table 2** (`primary_abstract_body`): proportion ratio (all) ≈ 2.74; per group
  must 5.12 / should 2.27 / need_to 4.04 / have_to 3.39 / required_to 1.51;
  48,940 markers (ME 28,553 / GM 20,387).
- **Table 3** (per-section subgroups): Abstract 4.19, Introduction 2.79,
  Methods 1.23, Results 16.97, Discussion 2.05.

> **Important mapping.** Table 3's **"Discussion" column = `sg_discussion_conclusion`**
> (Discussion **and** Conclusion combined), so articles whose closing section is
> labelled "Conclusion" are included.
>
> **重要.** Table 3 の「Discussion」列は `sg_discussion_conclusion`（Discussion と
> Conclusion を結合）に対応します。

## 5. Notes / 補足

- **Table 1 ≠ `describe-corpus`.** `describe-corpus` reports the full 10,899-row
  corpus including the 156 non-IMRaD articles. The manuscript analysis set is the
  10,743 with `is_non_imrad == false`. `run_06_table1.py` computes Table 1 from
  the parquet under that filter; `describe-corpus` is only an optional QC view.
  / `describe-corpus` は非 IMRaD 156 を含む 10,899 行を出すため Table 1 とは一致しません。
- **Determinism.** The whole path is rule-based / deterministic; reruns reproduce
  the numbers exactly. The R model uses fixed quadrature (no RNG).
- **Smoke test before the full download.** A quick sanity run on 20 articles:
  ```bash
  PYTHONPATH=src python -m normative_discourse.cli.main detect-deontic --dry-run --limit 20
  ```
- The R step writes `results/output_meta/session_info.txt` (R `sessionInfo()`) for
  the reviewer's environment record.
