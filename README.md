# normative-discourse-share

Open **reproduction package** for the study of *deontic markers* (normative
expressions such as *must / should / need to / have to / required to*) in
medical-education vs. general-medicine research articles.

医学教育誌と一般医学誌の原著における**義務表現（deontic markers）**頻度比較研究の
**再現パッケージ**（公開版）です。

This repository regenerates **Table 1-3 plus the sensitivity analyses and the speaker check** of the manuscript
from an access-controlled, already text-extracted corpus. It is a *self-contained subset*
of the full research repository: the code on the
text → corpus → detection → statistics path is included, together with the
eligibility-screening code for reference. Upstream retrieval, PDF download, and
Adobe PDF-Extract steps are intentionally omitted (the reproduction path never
goes online).

---

## Quick start

```bash
# 1. install the minimal dependencies (NOT `pip install -e .`)
pip install -r reproducibility/requirements.txt
# in R:  install.packages(c("arrow", "data.table"))   # for Table 2 & 3

# 2. place the Google-Drive data bundle (see reproducibility/README.md §2)

# 3. check inputs, then run everything and verify
python reproducibility/run_00_check_inputs.py
python reproducibility/run_all.py
python reproducibility/verify_numbers.py
```

**Full, step-by-step instructions (EN/JA) are in
[`reproducibility/README.md`](reproducibility/README.md).** Start there.

## What's in here

| Path | Contents |
| --- | --- |
| `reproducibility/` | Runnable, documented wrappers (`run_00`…`run_08`, `run_all`, `verify_numbers`) + the reproduction README |
| `src/normative_discourse/` | The analysis package — **reproduction subset only**: corpus builder, section parser, deontic detector, frequency analysis |
| `scripts/meta_analysis_deontic.R` | Poisson-lognormal random-effects meta-analysis (Table 2 & 3) |
| `scripts/meta_pln_lib.R` | Shared Poisson-lognormal model functions |
| `scripts/sensitivity_deontic.R` | Combined-section exclusion and leave-one-journal-out analyses |
| `scripts/list_combined_results_articles.py` | Inventory of combined Results articles |
| `scripts/quote_check/` | Speaker sampling, private review tools, public-label export and tally |
| `data/quote_check/speaker_labels.csv`, `speaker_labels.meta.json` | Public speaker labels and sample provenance |
| `results/output_sensitivity/`, `results/quote_check/` | Locally regenerated sensitivity and speaker reports |
| `tests/` | Synthetic tests without article passages |
| `scripts/strip_discussion_references.py` | Reference-stripping pass that produces the frozen corpus |
| `config/` | `section_overrides.toml` (per-article section fixes), `default_settings.toml` |
| `data/processed/med_teach_article_types.csv` | Article-type lookup (ships with the repo) |
| `src/normative_discourse/data_io/abstract_screener.py` | Reference screening prompt and model |
| `reproducibility/ref_screen_abstracts.py` | Optional reference screening wrapper |

The large inputs (text corpus, abstract cache, screening tables) are **not**
committed. They are collaborator-only input files placed under `data/` as
described in the reproduction README. Generated corpora and outputs are
regenerated by running the pipeline and are git-ignored.

> **Note on the package subset.** `src/` here is a pruned copy of the upstream
> package containing the modules the reproduction path imports, plus the
> screening module included for reference. The CLI
> exposes just three commands (`build-corpus`, `detect-deontic`,
> `analyze-frequency`). The upstream download/scraping subsystem and any
> institution-specific access configuration have been removed.

## Requirements

- Python ≥ 3.11
- R ≥ 4.5 with packages `arrow`, `data.table` (Table 2 & 3 only)

The main path (`run_all.py`) is rule-based and deterministic; reruns reproduce the published
numbers exactly. `verify_numbers.py` reads the regenerated outputs directly and
checks them against the manuscript (exits non-zero on any mismatch).

## Use of AI tools

The data-processing and analysis code in this repository was written with the
assistance of Claude Code (Anthropic), an AI coding assistant. The authors
specified the analyses, reviewed the code, checked intermediate outputs
(including manual review of flagged section-segmentation records), and verified
the final numbers against the manuscript; the authors take full responsibility
for the code and results.

Eligibility screening of titles and PubMed abstracts was assisted by a large
language model (Gemini 3.1 Flash-Lite, preview version; Google), with a subset
of its decisions reviewed manually. The main reproduction path uses the frozen
screening decisions and human-review corrections.
Reference code is in `src/normative_discourse/data_io/abstract_screener.py`
(prompt and model ID) and `reproducibility/ref_screen_abstracts.py` (standalone wrapper).

Results speaker drafts were produced by Claude Sonnet subagents in Claude Code,
using `scripts/quote_check/prompt_template.md`; a human rater saw the drafts and made
the final judgements, so their agreement is not independent. No speaker-check script calls a model.
